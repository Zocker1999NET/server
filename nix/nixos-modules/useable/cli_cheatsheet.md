| Tool | Description |
|------|-------------|
| `bandwhich` | Network utilization by process, connection, and remote IP/hostname |
| `bat` | Modern cat replacement with syntax highlighting and Git integration |
| `batdiff` | Show diff with bat syntax highlighting |
| `batwatch` | Watch commands and display output with bat |
| `prettybat` | Format and colorize source code files |
| `batmon` | Interactive TUI for battery status and health monitoring |
| `bmon` | Portable bandwidth monitor and rate estimator |
| `bluetuith` | TUI for managing Bluetooth connections on Linux |
| `csvcut` | Filter and extract columns from CSV files |
| `csvgrep` | Search for patterns in CSV files |
| `csvsort` | Sort CSV files by column data |
| `csvstat` | Print statistics about CSV columns |
| `dig` | DNS lookup utility for querying DNS servers |
| `ethtool` | Query and control network driver and hardware settings |
| `fzf` | Command-line fuzzy finder for interactive filtering |
| `fuser` | Identify processes using files or sockets |
| `intel-gpu-tools` | Tools for Intel DRM driver development and debugging |
| `iotop` | Display I/O usage by processes |
| `jq` | Lightweight JSON processor for parsing and transforming data |
| `killall` | Kill processes by name |
| `manix` | Fast documentation searcher for Nix and NixOS |
| `massren` | Rename multiple files using text editor |
| `mtr` | Network diagnostic tool combining ping and traceroute |
| `nethogs` | Network monitoring tool grouping bandwidth by process |
| `noping` | Ping multiple hosts in parallel using liboping |
| `nvtop` | ncurses-based GPU monitoring for AMD, Intel and NVIDIA GPUs |
| `oping` | Ping multiple hosts in parallel using liboping |
| `pextract` | Extract process information from /proc |
| `psitop` | Real-time pressure stall information display |
| `pstree` | Display process tree showing parent-child relationships |
| `pv` | Monitor progress of data through a pipeline |
| `reptyr` | Reparent running program to new terminal |
| `smem` | Memory usage reporting with shared memory calculations |
| `sponge` | Soak up standard input and write to a file |
| `speedtest-cli` | Command-line internet bandwidth testing |
| `up` | Linux tool for writing and testing data pipelines |
| `usbtop` | Display USB bus bandwidth usage |


## Frontend ZSH Plugins (Frontend Systems Only)

| Tool | Description |
|------|-------------|
| `autojump --stat` | Show autojump statistics |
| `bofh` | Print random BOFH excuse |
| `bofh_cow` | Print BOFH excuse in cowthink bubble |
| `cde` | Change directory without clearing stack |
| `clip` | Copy or show clipboard |
| `disable_auto_notify` | Temporarily disable auto-notify |
| `enable_auto_notify` | Re-enable auto-notify |
| `gtr` | Create signed git release tag |
| `j` | Jump to directory (autojump) |
| `jc` | Jump to child directory |
| `jo` | Open file manager in directory |
| `pbcopy` | Copy to clipboard |
| `pbpaste` | Show clipboard contents |

| Keybinding | Description |
| `Alt+d` | Delete prompt prefix from current line |
| `Alt+Down` | Move into first child directory |
| `Alt+Left` | Go to previous directory |
| `Alt+Right` | Go to next directory |
| `Alt+Up` | Move to parent directory |
| `Ctrl+K+L` | lowercase word |
| `Ctrl+K+U` | UPPERCASE word |
